# Redirecionamento para a avaliação final do TCC

O texto-base com campos entre colchetes foi substituído após a execução do benchmark,
a crítica do orientador e a comparação BM25 versus recuperação densa.

Para escrever o TCC, use estes arquivos:

1. `evaluation/RELATORIO_COMPLETO_REVISAO_METRICAS.md`: capítulo consolidado;
2. `evaluation/TABELAS_FINAIS_TCC.tex`: tabelas finais;
3. `evaluation/PACOTE_ENTREGA_TCC.md`: checklist, afirmações permitidas e artefatos
   históricos;
4. `evaluation/results/bm25_baseline/retrieval_comparison.csv`: dados da comparação.

O BM25 está integrado como recuperador principal. A configuração densa permanece como
comparação e como origem histórica das métricas de decisão de responder ou recusar.
A correção factual das respostas geradas não foi medida e não deve ser inferida das
métricas de recuperação.
